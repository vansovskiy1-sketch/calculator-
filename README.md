# Dota 2 Boost Calculator v6

Статический калькулятор для GitHub Pages.

## Что нового в v6

- Трёхступенчатая визуальная структура формы: параметры → условия → аккаунт.
- Визуальная шкала MMR для прогрессивного соло-буста.
- Раскрываемый подробный breakdown стоимости.
- Модальное окно подтверждения перед отправкой заказа в Telegram.
- Улучшенная мобильная компоновка со sticky-панелью итога.
- Сохранена логика пати-буста по играм и MMR-диапазонам.
- Кор-роль всегда доступна и добавляет +100%.
- Смурфпулл — одна опция, +15% от 3500 MMR.
- Порядочность и вежливость рассчитываются автоматически по введённым значениям.
- Для соло-буста показывается ориентировочное количество игр при +30 MMR за победу; показатель не влияет на цену.
- Ориентировочное число игр включается в заказ, отправляемый в Telegram.

## GitHub Pages

Загрузите в корень репозитория:

- `index.html`
- `style.css`
- `app.js`
- `pricing.js`

После commit включите GitHub Pages через `Settings → Pages → Deploy from a branch → main → / (root)`.

- Перед открытием Telegram показывается полная проверка заказа: база, точные суммы доплат, параметры аккаунта и итог.
- История сохраняется после подтверждения заказа.
- Каждый подтверждённый заказ получает локальный номер вида D2-XXXXXX.
