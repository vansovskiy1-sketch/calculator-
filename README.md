# Dota 2 Boost Calculator

Статический кликабельный калькулятор для GitHub Pages.

## Услуги

- ММР буст — прогрессивный расчёт по диапазонам MMR.
- Пати буст — цена за вин с дополнительными условиями, включая **даблы до 5620 MMR: +50%**.
- Калибровка — цена за вин с дополнительными условиями.
- Коучинг — цена за час по MMR.
- Боевой кубок — цена по тиру.

## Пати-буст: дополнительные условия

- Даблы до 5620 MMR — +50% к фиксу.
- Даблы после 5620 MMR — +30% к фиксу.
- Кор роль после 5620 MMR — +30% к фиксу.
- Смурфпулл от 3500 MMR — +15%.
- Лоу поряда 0–4k — +15%.
- Лоу поряда 4–6k — +15%.
- Лоу поряда 6k+ — +15%.
- Смурфпулл аккаунт от 3500 MMR — +15%.

## GitHub Pages

Загрузите содержимое папки в корень репозитория и включите:
`Settings → Pages → Deploy from a branch → main → / (root)`.

`index.html` должен находиться в корне репозитория.
