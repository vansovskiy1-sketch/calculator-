# Dota 2 Boost Calculator

Статическое веб-приложение на HTML/CSS/JavaScript для расчёта стоимости:

- ММР буста;
- пати буста;
- калибровки аккаунта;
- коучинга;
- боевого кубка.

## Запуск локально

Откройте `index.html` в браузере.

Для более стабильной работы локально можно использовать любой простой HTTP-сервер, например:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css` и `app.js` в корень репозитория.
3. В репозитории откройте **Settings → Pages**.
4. В качестве Source выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/root`.
6. Сохраните настройки — GitHub Pages выдаст ссылку на сайт.

Приложение не использует сервер, базу данных или сборщик — оно работает полностью в браузере.

## Логика расчёта

Для ММР буста цена считается прогрессивно по диапазонам: каждый участок пути тарифицируется по своей ставке за 100 MMR. Доплаты +15%/+30% складываются и применяются к базовой стоимости заказа.

Для пати-буста и калибровки ставка выбирается по MMR и умножается на количество побед.

Для коучинга ставка выбирается по MMR и умножается на количество часов.

Для боевого кубка используется фиксированная цена по тиру.
