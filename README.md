# Dota 2 Boost Calculator

Статический калькулятор для GitHub Pages. Не требует сервера или сборки.

## Возможности
- ММР буст с прогрессивным расчётом по диапазонам.
- Пати буст по победам.
- Калибровка по победам.
- Коучинг по часам.
- Боевой кубок по тиру.
- Дополнительные условия с переключателями и автоматическим расчётом наценок.
- Для пати-буста: двойной жетон до 5620 MMR — +50%, выше 5620 — +30%.
- Адаптивный интерфейс для desktop и mobile.
- Доступные фокус-состояния и поддержка `prefers-reduced-motion`.

## GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория.
2. Откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. Сохраните настройки.

## Локальный запуск
Откройте `index.html` в браузере или запустите любой простой статический HTTP-сервер.
